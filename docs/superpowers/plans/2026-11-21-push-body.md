# The body behind the push: implementation plan

**Goal:** give the push strokes' hands a body of mass M_b that the balls' resistance slows, instead of re-timing the
hands to the head's pace at the restart. Then run the discriminating card for G2.

**Architecture:**
- **The deficit.** On each impact step the integrator advances the body's deficit δ from the grips' coupling along aim
  and the press.
- **The clock.** It appends τ and τ' to a `BodyClock` held on the track's `Anchor`, and the path reads its time from
  that clock.
- **The hand-over.** At the body's end the clock hands over to a fixed-rate anchor, and the finish runs as today.

**Spec:** `docs/superpowers/specs/2026-11-20-push-body-design.md` (amended after review, 2026-11-21). Executed
natively in this session, with no Superpowers plugin.

## Global constraints

- **The gate.** `track.push !== null && finishKind(track) !== "check"`. Every other stroke plays to the bit as before.
  The no-push baseline, `tests/engine/impact/fixtures/noPushBaseline.json`, is never re-captured.
- **F_g** is `(HandLoad.force − (feedForward − dip)) · aim`, the press excluded. It never includes the feed-forward.
- **The press.** On gated strokes it acts on the body only, `M_b·dδ/dt = F_g − F_press`, with δ clamped to
  [0, v_plan].
- **The pace point.** `v_plan` is the plan's along-aim socket pace, `plannedPath(...).socketVelocity · aim`, at the
  body's τ.
- **M_b.** It is the reference value `pushBodyMass`: 2.9 kg, bounds [0.9, 4.9], provenance "analogue". It is never
  fitted, so it does not go in `FREE_PARAMS`. M_b = Infinity holds δ at 0.
- **Engine 0.43.0.**
- **The run's stop rules (spec §3).**
  - If the ∞ row fails the roll bands, report and stop.
  - If 2.9 kg fails, play 0.9 and 4.9 kg, report all three and stop.
  - Never try another value or tune anything.
  - Re-pin nothing until the 2.9 kg row passes.
- **Public repo:** cite sources (URL, date, SHA-256 where it can be fetched), never mirror them.
- **No Co-Authored-By trailer or other attribution. Commit by explicit path.**

## Review focus

1. **A stroke that never strikes** (`impact-no-strike`, a head stopped in the turf): no clock is created, and the
   impact ends as before.
2. **A strike that closes again after its departure** (C3F's taps): δ keeps integrating across the gap with F_press 0,
   and nothing resets it.
3. **v_b reaching 0 mid-push:** the hand-over at rate 0 gives `anchoredTime` = Infinity, and FOLLOW_CAP ends the
   stroke without a throw or a NaN.
4. **A replay of the practised run** (`playJudged`): the clock is rebuilt per run, never shared between plays. The
   arrays are created inside the impact and never on the prepared plan.
5. **`retimeFinish` triggered while the clock is live** (`plannedTime ≥ push.end` before the hand-over): the body's
   end comes first in that step, so `retimeFinish` always sees a fixed-rate anchor.

Each of these has a test in Task 3.

### Task 2: `BodyClock`, a new form of `Anchor`

**Files:**
- Modify: `src/engine/impact/track.ts` (`Anchor`, `warpedBase`, `anchoredBase`).
- Test: `tests/engine/impact/track.test.ts`.

**Interfaces:**
- Produces this type:
  ```ts
  export interface BodyClock {
      readonly at: number;   // the strike, s
      readonly dt: number;
      readonly tau: number[]; // τ at at + i·dt; tau[0] = at
      readonly rate: number[]; // τ' at the same instants
  }
  ```
  `Anchor` gains `readonly body?: BodyClock`. While it is present, `rate` is 1, `by` is ZERO and `warp` is null.
- Produces `bodyAnchor(at: number, dt: number): Anchor`, which returns `{ at, rate: 1, by: ZERO, warp: null, body:
  { at, dt, tau: [at], rate: [1] } }`.
- Produces `handOver(track: PreparedTrack, t: number): PreparedTrack`, which replaces a body anchor at t with
  `{ at: t, rate: τ'(t), by: ZERO, warp: null }` and an offset `shift = τ(t) − t`. To carry the offset, `Anchor` gains
  `readonly shift?: number`: under a fixed rate, τ = at + shift + rate·(t − at), and `anchoredBase` inverts it alike.
  Default 0, so every existing anchor is unchanged.
- **Reading the clock.** `warpedBase` with `body` interpolates τ linearly between samples, takes τ' from `rate` at
  the sample before and τ'' = (rate[i+1] − rate[i])/dt, which is 0 at and past the last sample. Past the last sample
  it extrapolates τ at the last rate. `anchoredBase` with `body` inverts it by bisection over the samples, and past
  the last sample at the last rate, which is Infinity at a rate of 0.

- [ ] **Write the tests.**
  - A body anchor whose samples have rate ≡ 0.6 gives the same `pathAt`, `plannedTime` and `anchoredTime` as
    `{ at, rate: 0.6, warp: null }`, to 1e-12, at sample instants and between them.
  - Past the last sample, `plannedTime` extrapolates at the last rate. At a last rate of 0, `anchoredTime` returns
    Infinity.
  - `handOver` is continuous: `pathAt` just before and at t agree in socket and socketVelocity to 1e-9.
  - An anchor without `shift` plays to the bit as before (an existing `reanchor` case).
- [ ] **Run** `npx vitest run tests/engine/impact/track.test.ts`. Expect the new tests to fail.
- [ ] **Implement** as in the Interfaces block. `handsAt` and `pathAt` need no change beyond going through
  `warped`.
- [ ] **Check:** `track.test.ts` and `npx tsc --noEmit` pass.
- [ ] **Commit** "BodyClock: the body's per-step time as an anchor form; the hand-over at a fixed rate with its
  offset".

### Task 3: The body in the impact (spec §2.1–§2.4)

**Files:**
- Modify: `src/engine/impact/track.ts` (`HandLoad.coupling`, the press kept off gated strokes, the `intent` comment).
- Modify: `src/engine/impact/integrate.ts` (the strike, each step, the restart, the end, the impact's end).
- Test: create `tests/engine/impact/pushBody.test.ts`.

**Interfaces:**
- Consumes `bodyAnchor` and `handOver` (Task 2) and `track.hands.pushBodyMass` (Task 1).
- Produces `bodyStroke(track: PreparedTrack): boolean`, exported from `track.ts`: the gate.
- Produces `HandLoad.coupling: Vec3`, the force less `(feedForward − dip)`. On gated strokes `pushIntent` stays out of
  `fed`, and `intent` still reports it.
- Produces `stepBody(track, load: HandLoad, grip: GripState, t: number, dt: number): PreparedTrack` in `integrate.ts`.
  It appends the next τ and τ', and returns the track handed over when an end condition holds.
- **The deficit.** `δ` lives on `GripState` as `bodyDeficit: number` (0 in `newGripState`). Each step:
  - δ ← clamp(δ + dt·(F_g − F_press)/M_b, 0, v_plan);
  - τ' = (v_plan − δ)/v_plan, and τ'' follows from that step's change;
  - with M_b = Infinity, δ stays 0.
- **The strike.** At the step that latches `grip.striker` on a gated stroke, `played` gains `bodyAnchor(t, dt)`.
- **The restart.** On a gated stroke the restart sets `restarted` and calls nothing.
- **The ends.** Checked at the top of each step after the strike, before `retimeFinish`'s trigger: `plannedTime ≥
  push.end`, or `≥ push.pendulum`, or v_b ≤ 0. Then `played = handOver(played, t)`. At the impact's end, if the clock
  is still live, `handOver(played, steps·dt)` runs before the `retimeFinish` fallback and `continueStroke`.

- [ ] **Write the tests** in `pushBody.test.ts`, spec §3's six and the Review Focus's five:
  1. The full roll's text book with no balls (`setup.balls` empty, the track forced past contact): δ stays below
     1e-3·v_plan.
  2. With `stepBody` driven by a stub load of constant coupling 150 N, F_press 92.2 N and M_b 2.9 kg, δ grows at
     (150 − 92.2)/2.9 m/s² to 1e-9. At 50 N, δ is 0 after one step.
  3. With M_b = Infinity on the canonical full roll, the run's `anchor.rate` is 1 at the hand-over.
  4. Gated off: `noPushBaseline.json`'s three strokes match it to the bit (the existing test, run unchanged).
  5. The canonical full roll at 2.9 kg: across the hand-over, the hands' path is continuous in place and pace to
     1e-9.
  6. A stop with a push (`finishKind` "check") plays to the bit as at HEAD. Capture its pin first from HEAD, in this
     step, before the engine changes.
  - RF1: a no-strike stroke, the existing `impact-no-strike` case, plays as before.
  - RF2: C3F's run keeps δ across its face gap. δ at the gap's end is at least δ at its start, minus F_press·gap/M_b.
  - RF3: a stub load that drives v_b to 0 ends in `follow-cap`, with no NaN in the trace.
  - RF4: two `playJudged` runs of the same shot give the same trace to the bit.
  - RF5: `retimeFinish` never sees `anchor.body`. Assert it inside a probe hook, or by checking that `run.anchor`
    has no body.
- [ ] **Run** `npx vitest run tests/engine/impact/pushBody.test.ts`. Expect failures.
- [ ] **Implement** as in the Interfaces block. Reword `HandLoad.intent`'s doc comment (spec §2.3).

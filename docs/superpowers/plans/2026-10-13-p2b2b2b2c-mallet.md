# P2b.2b.2b.2c — The Mallet: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The head becomes a cylinder or a rounded box, the box's moment about the shaft set from a measurement. The
shaft is a uniform rod with mass, rigid on the head. The default profile becomes a real, market-central modern mallet:
the Pidcock 2000 11", with Plummer's typical figures filling its gaps.

**Architecture:**

- `shape.ts` (new) holds the head's section, a discriminated union (`cylinder` | `box`), and the rounded box's
  geometry: its core box, signed distance, normal and region.
- `contacts.ts` dispatches each head primitive on `shape.kind`. The cylinder's branches keep their arithmetic
  byte-for-byte, so every step has a bit-identical before and after. `faceContact` stays cylinder-only.
- `rigidBody.ts` gains `boxInertia` from the measured moment about the shaft.
- `track.ts` gains `malletBody`: the head and a thin uniform shaft as one rigid body. The swung body and the carry's
  body build on it. The shaft's weight acts at its own centre, in the integrator's loads, the hands' feed-forward and
  the pendulum's weight term.
- `SwingProfile.mallet` takes a head union (`round` | `box`) and a shaft mass. The default switches last.
- The tasks land in the spec's ratchet order (§7.2):
  - the baseline and the sources;
  - the union, cylinder only;
  - the rounded box's collider;
  - the box's inertia and profile;
  - the shaft, with no mass anywhere;
  - the mallet's reference data;
  - the default switched;
  - the user's pre-flight gate;
  - the gates and the version;
  - the probes and the documents.

**Tech Stack:** TypeScript (strict, `noUncheckedIndexedAccess`, `verbatimModuleSyntax`), Vitest, ESLint, Prettier. No
new dependencies. `npx --yes tsx` runs the scripts.

**Decisions made while planning.** Task 10 folds each into the spec's amendment note. Decision 1 corrects a sentence
of the spec, and decision 5 chooses how the gate's "old head" figures are taken; the user accepted both on
2026-10-13.

1. **`headBottom` is also the head–turf contact point**, not only where `surfaceAt` is sampled (spec §3.4 says "used
   only to sample `surfaceAt`"). `headTurfContact` acts at it. A box's support point with sign(0) = 0 puts a level
   box's turf contact on its bottom face's midline, under the centre, as the level cylinder's is.
2. **The regions are listed per shape.** `HEAD_REGIONS` stays the cylinder's five, in their order. The box's are
   `BOX_REGIONS = ["face", "edge", "corner", "side", "top", "bottom", "back"]`, and `regionsOf(shape)` picks the list.
   The integrator builds a face–ball pair's region timelines from that list, so a cylinder's run records exactly what
   it records now.
3. **The box's sign convention.** A body coordinate p_i ≥ 0 counts as positive for the normal's sign and for `face`
   against `back` (as the cylinder's x ≥ 0 does), and for `top` against `bottom`. So the head's own centre resolves to
   `side` along +y with no throw: of its q, (−L/2, −h_y, −h_z) with e = 0, y and z tie largest, and the tie goes to y.
4. **`StanceGeometry.headRadius` becomes `faceHalfHeight`**, its meaning (ρ, the socket's height above the head's
   centre). Its three readers and the tests' geometry objects follow.
5. **The old head's gate figures come from Task 1's baseline**, run on `main` before any change, not from a legacy
   profile re-run after the switch.
   - The switch re-fits `swing.json`: the rolls' hands' tempo and the swing presets' effort and tempos.
   - It also recomputes every stance's `handsAhead` from `REFERENCE_GEOMETRY`.
   - Re-running the old head after the switch would mix the old mallet with the new fits.
   - The baseline run is the P2b.2b.2b.2b engine exactly, which is what spec §9 compares against.
6. **The twist's figures** (spec §9):
   - the peak |ω_s| is the largest |ω·s| over the impact's steps, s the shaft's axis;
   - the yaw at release is asin(f·n̂) at the last step the face pressed the striker's ball, f the face's normal and
     n̂ = aim × ẑ: the face's turn out of the swing plane, positive to the right.
7. **The twist hold** (spec §9) is `holdTwist(track, inertiaZ)`, exported from `track.ts` and called by nothing in the
   engine. The gate's held runs go through `validateImpact`, `prepareImpact`, `holdTwist` and `integrateStroke`. They
   skip the handover, which their figures do not read.
8. **The probes' force-table head is pinned to the Jaques round head**, 9" (0.2286 m) by 3" (`headDiameter`), the head
   `mallet.json`'s `headDiameter` note quotes. A force table is the bare cylinder's instrument (spec, Decisions), so
   `impactProbe.ts` and `swingProbe.ts` must not change their force strokes when the default's `headLength` moves to
   11".
9. **`REFERENCE_GEOMETRY` is computed from the default mallet object** with the helpers `contactPose` uses
   (`headShapeOf`, `faceHalfHeight`), so an upright preset's hands and its pose agree to the bit after the switch, as
   they do now.
10. **The default profile's `shaftMass` is 0 until the switch** (Task 5 to Task 7): ratchet step 4, "`shaftMass` 0
    everywhere".
11. **`mallet.json`'s new fields land in Task 6, unread.** The `headLength` value moves to 11" in Task 7, with the
    switch: at 9" the default's 146 kg·cm² lies past the box's realisable maximum (133.4 kg·cm²), so the
    realisability test arrives with the switch.
12. **The shaft's bound runs 0.227–0.398 kg**, as spec §5.2 writes it (RPM's 8 oz is 0.2268 kg).

## Review Focus

The spec implies each input below, but none of its listed tests exercises it. The task that owns each one pins it with
a test.

1. **A ball centre at the box head's own centre, or exactly on a body axis plane** (p_y = 0, p_z = 0). The cylinder
   throws a RangeError for a centre on its axis; the box has a normal everywhere, and must give one, with no NaN and no
   throw. Pinned in Task 3 ("resolves a centre at the head's centre to the side, with no throw").
2. **An edge radius at its limits.** e = 0, a sharp box, must plan and strike normally. An e just under
   min(h_y, h_z, L/2) is accepted, and e equal to it is rejected with a RangeError naming `edgeRadius`. Pinned in
   Task 3 (`validateImpact`'s rows) and Task 4 ("plans and strikes with a sharp box, e = 0").
3. **A rectangular face** (`faceWidth` ≠ `faceHeight`). The socket, the stance's ρ and the face's flat height must
   come from the face's height, not its width, and I_y must take the section's correction. Pinned in Task 4 ("puts the
   socket at half the face's height on a rectangular face").
4. **A mirrored stroke with the box head.** It must mirror exactly across y = 0, as every tracked drive does. The
   box's sign convention (decision 3) must not break the symmetry. Pinned in Task 4 ("gives a box-head setup mirrored
   across a vertical plane an exactly mirrored impact").
5. **The top hand below the shaft's mid-point** (r < ℓ/2). The shaft's weight term m_s·g·(ℓ_h − h_z − ℓ/2) is then
   negative and opposes the head's. The pendulum must still swing at 2π·√(I_P/W). Pinned in Task 5 ("swings freely
   about the top hand at 2π·√(I_P/W)", at r = 0.3 m).

```ts
/**
 * A probe that keeps only what the figures read: the largest |ω·s| (s the shaft's axis), the highest ball centre, and
 * the head at the last step the face pressed the striker's ball.
 */
function twistProbe(striker: string): ImpactProbe & { peak: number; highest: number; release: HeadState | null } {
    const probe = {
        peak: 0,
        highest: -Infinity,
        release: null as HeadState | null,
        step(s: ImpactSnapshot): void {
            const shaft = rotate(s.head.orientation, vec3(0, 0, 1));
            probe.peak = Math.max(probe.peak, Math.abs(dot(s.head.angularVelocity, shaft)));
            for (const b of s.balls) {
                probe.highest = Math.max(probe.highest, b.position.z);
            }
            if (s.contacts.some((c) => c.key === `face/${striker}` && c.normalForce > 0)) {
                probe.release = s.head;
            }
        },
    };
    return probe;
}

function run(label: string, setup: ShotSetup): void {

        const plan = planStroke(setup, WORLD);
        const probe = twistProbe(setup.striker);

        const drive = plan.contact.drive;
```

```ts
/** The core box's half-extents c = (L/2 − e, h_y − e, h_z − e) (m) of a box head `length` (m) long (design §3.2). */
export function boxCore(shape: BoxShape, length: number): Vec3 {
    const e = shape.edgeRadius;
    return vec3(length / 2 - e, shape.halfWidth - e, shape.halfHeight - e);
}

/** −1 below zero, else 1: a coordinate of zero counts as positive (plan decision 3). */
function side(value: number): number {
    return value >= 0 ? 1 : -1;
}

/**
 * The rounded box's signed distance d = ‖max(q, 0)‖ + min(max_i q_i, 0) − e from a body-frame point `p`, with
 * q_i = |p_i| − c_i (design §3.2), its outward normal ∇d and its region, by the count of positive q_i: x alone, the
 * `face` (p_x ≥ 0) or the `back`; y alone, a `side`; z alone, the `top` (p_z ≥ 0) or the `bottom`; two, an `edge`;
 * three, a `corner`. A point inside the core takes the axis of its largest q_i, ties to x, then y, then z, and that
 * axis's region. With one positive q_i the distance is that q_i less e, exactly.
 */
export function boxDistance(shape: BoxShape, length: number, p: Vec3): BoxDistance {
    const c = boxCore(shape, length);
    const e = shape.edgeRadius;
    const qx = Math.abs(p.x) - c.x;
    const qy = Math.abs(p.y) - c.y;
    const qz = Math.abs(p.z) - c.z;
    const sx = side(p.x);
    const sy = side(p.y);
    const sz = side(p.z);
    const front = sx > 0 ? "face" : "back";
    const upper = sz > 0 ? "top" : "bottom";
    const count = (qx > 0 ? 1 : 0) + (qy > 0 ? 1 : 0) + (qz > 0 ? 1 : 0);
    if (count <= 1) {
        // One positive q_i, or none (inside the core): the axis of the largest, ties to x, then y, then z.
        if (qx >= qy && qx >= qz) {
            return { distance: qx - e, normal: vec3(sx, 0, 0), region: front };
        }
        if (qy >= qz) {
            return { distance: qy - e, normal: vec3(0, sy, 0), region: "side" };
        }
        return { distance: qz - e, normal: vec3(0, 0, sz), region: upper };
    }
    const ox = Math.max(qx, 0);
    const oy = Math.max(qy, 0);
    const oz = Math.max(qz, 0);
    const size = Math.sqrt(ox * ox + oy * oy + oz * oz);
    return {
        distance: size - e,
        normal: vec3((sx * ox) / size, (sy * oy) / size, (sz * oz) / size),
        region: count === 2 ? "edge" : "corner",
    };
}
```

With one positive q_i, that q_i is the largest, so the `count <= 1` branch serves both cases.

```ts
/**
 * Principal moments of a box head (P2b.2b.2b.2c design §4.1) whose every slice along body x has the same section,
 * half-extents h_y and h_z, so its weighting varies along x alone, as end inserts do: I_z the measured moment about
 * the shaft `aboutShaft`; I_y = I_z + m·(h_z² − h_y²)/3; I_x = m·(h_y² + h_z²)/3. The edge rounding is ignored, an
 * error of order (e/h)². Throws a RangeError outside the realisable m·h_y²/3 ≤ I_z ≤ m·(L²/4 + h_y²/3), from all the
 * mass on the shaft's axis to all of it at the faces.
 */
export function boxInertia(
    mass: number,
    length: number,
    halfWidth: number,
    halfHeight: number,
    aboutShaft: number,
): Vec3 {
    const across = halfWidth * halfWidth;
    const up = halfHeight * halfHeight;
    const least = (mass * across) / 3;
    const most = mass * ((length * length) / 4 + across / 3);
    if (!(aboutShaft >= least && aboutShaft <= most)) {
        throw new RangeError(
            `the box head's moment about the shaft must lie in [${least}, ${most}] kg·m² for its mass, length and ` +
                `width (got ${aboutShaft})`,
        );
    }
    return vec3((mass * (across + up)) / 3, aboutShaft + (mass * (up - across)) / 3, aboutShaft);
}
```

On a square section `up - across` is 0, so I_y is `aboutShaft + 0`, exactly I_z.

In `src/engine/impact/track.ts`, before `swungBody`:

```ts
/**
 * The mallet as one rigid body (P2b.2b.2b.2c design §4.2): `head` and its shaft, a thin uniform rod of mass m_s and
 * length ℓ from the socket (0, 0, h_z) up body z. M = m + m_s, δ = m_s·(h_z + ℓ/2)/M along body z, and
 * I' = (I_x + e, I_y + e, I_z), e = m·δ² + m_s·((h_z + ℓ/2 − δ)² + ℓ²/12). With no shaft mass it is the head itself:
 * its mass, its inertia and offset 0, with no added zero terms.
 */
export function malletBody(head: MalletHead): SwungBody {
    const { mass: rod, length } = head.shaft;
    if (rod === 0) {
        return { mass: head.mass, inertia: head.inertia, offset: 0 };
    }
    const mass = head.mass + rod;
    const rise = head.socket.z + length / 2;
    const offset = (rod * rise) / mass;
    const extra = head.mass * offset * offset + rod * ((rise - offset) * (rise - offset) + (length * length) / 12);
    const I = head.inertia;
    return { mass, inertia: vec3(I.x + extra, I.y + extra, I.z), offset };
}

/**
 * `base` with point masses rigid on its up axis, each `mass` (kg) at `height` (m) above the head's centre: the
 * combined mass, centre and principal inertia by the parallel-axis rule.
 */
function withPoints(base: SwungBody, points: readonly { readonly mass: number; readonly height: number }[]): SwungBody {
    let mass = base.mass;
    let moment = base.mass * base.offset;
    for (const p of points) {
        mass += p.mass;
        moment += p.mass * p.height;
    }
    const offset = moment / mass;
    let extra = base.mass * (base.offset - offset) * (base.offset - offset);
    for (const p of points) {
        extra += p.mass * (p.height - offset) * (p.height - offset);
    }
    const I = base.inertia;
    return { mass, inertia: vec3(I.x + extra, I.y + extra, I.z), offset };
}
```

```ts
/** The P2b.2b.2b.2b head's I_z: the uniform 1.0 kg Jaques cylinder, 9 in by 3 in; 47.2 kg·cm². */

    "half-roll",
    "full-roll",
    "pass-roll",
    "single-ball",
    "drive",
    "stop-ac",
    "stop-gc",
];

/** As gateFigures.mts's: the twist's peak and the head at the face's last press on the striker's ball. */
function twistProbe(striker: string): ImpactProbe & { peak: number; release: HeadState | null } {
    const probe = {
        peak: 0,
        release: null as HeadState | null,
        step(s: ImpactSnapshot): void {
            const shaft = rotate(s.head.orientation, vec3(0, 0, 1));
            probe.peak = Math.max(probe.peak, Math.abs(dot(s.head.angularVelocity, shaft)));
            if (s.contacts.some((c) => c.key === `face/${striker}` && c.normalForce > 0)) {
                probe.release = s.head;
            }
        },
    };
    return probe;
}

function held(label: string, setup: ShotSetup): void {
    try {
        const { contact } = planStroke(setup, WORLD);
        const sink = sinkSolver(WORLD);
        validateImpact(contact, setup.balls, WORLD, sink);
        const prepared = prepareImpact(contact, setup.balls, WORLD, sink);
        const track = prepared.drive as PreparedTrack;
        const probe = twistProbe(setup.striker);
        const { run } = integrateStroke({ ...prepared, drive: holdTwist(track, OLD_IZ) }, { probe }, true);
        const face = probe.release === null ? null : rotate(probe.release.orientation, vec3(1, 0, 0));
        const yaw = face === null ? NaN : (Math.asin(dot(face, pitchAxis(track.arc.aim))) * 180) / Math.PI;
        console.log(
            `${label} held at I_z ${(OLD_IZ * 1e4).toFixed(1)} kg·cm² (the new body's ` +
                `${(track.body.inertia.z * 1e4).toFixed(1)}): impact ${(run.duration * 1e3).toFixed(2)} ms; peak ` +
                `|ω_s| ${probe.peak.toFixed(4)} rad/s; yaw at release ${yaw.toFixed(4)}°`,
        );
    } catch (error) {
        console.log(`${label} held: threw ${(error as Error).name}: ${(error as Error).message}`);
    }
}

for (const type of ORDER) {
    for (const speed of [2, 3]) {
        const base = canonicalSetup(type, { world: WORLD });
        held(`${type} ${speed} m/s`, { ...base, stroke: { ...base.stroke, backswing: backswingFor(base, speed, WORLD) } });
    }
}
const gc = canonicalSetup("stop-gc", { world: WORLD });
const off = { ...gc, stroke: { ...gc.stroke, contact: { up: gc.stroke.contact.up, side: 0.01 } } };
held("stop-gc 3 m/s side 10 mm", { ...off, stroke: { ...off.stroke, backswing: backswingFor(off, 3, WORLD) } });
```

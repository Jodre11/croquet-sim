# The body behind the push, amendment A1: implementation plan

**Goal:** let the push body run ahead of the plan under the press while the head is slower than the striker's ball,
then run the discriminating card for G2 again.

**Architecture:** restore the reverted body (bce3ab0, ca6478f, reverted in 5ecad80), then change one rule in
`stepBody`: the floor δ ≥ 0 and the rate clamp τ' ≤ 1 go, and the press drives a lead only while W < w₁. The
integrator passes W and w₁ from the step-start state.

**Spec:** `docs/superpowers/specs/2026-11-20-push-body-design.md`, amendment A1 (29bbeb6). The first plan,
`2026-11-21-push-body.md`, holds for everything A1 does not change. Executed natively.

## Global constraints

- **The rule.** `M_b·dδ/dt = F_g − F_lead`, `δ ≤ v_plan`, `F_lead = F_press` while `δ > 0 || W < w₁`, else 0.
- **W, w₁:** the head's and the striker's ball's centre-of-mass velocity · aim, from the state at the step's start.
  Not `strikerPace`.
- **τ'** may exceed 1; it stays ≥ 0. τ'' is the change in τ' over the step, as before.
- **Engine 0.44.0.** 0.43.0 named the reverted floor.
- **The run (spec §3).** ∞ first: every row must equal `2026-11-21-push-body-inf`'s to the printed digits, or stop.
  Then 2.9 kg; if it fails, 0.9 and 4.9 kg, report all and stop. No other value, no tuning, no re-pin before a pass.
- **No attribution. Commit by explicit path.**

## Review focus

1. **A lead at the impact's end:** the hand-over rate exceeds 1 and the follow-through stays finite; `retimeFinish`
   still bounds the finish.
2. **W ≥ w₁ from the strike** (a head faster than its ball at first contact): no lead ever forms; δ only closes.
3. **The striker's ball leaving the lawn's bed or the impact's ball list mid-impact:** no w₁, so no lead (F_lead 0
   unless δ > 0).
4. **M_b = ∞:** bit-identical to the first run's ∞ (the reproduction row).
5. **Determinism:** two plays of one stroke match to the bit.

Each has a test in Task 1, except 4, which the run checks.

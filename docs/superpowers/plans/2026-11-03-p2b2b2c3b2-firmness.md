# P2b.2b.2c.3b.2 the body's backswing, the arms' assist and the found firmness Implementation Plan

Executed natively in the main session, task by task; the gate stops for the user.

**Goal:** A body limit on the head's rise on every type, the arms' strength driving a hands-led downswing in place of
the tempo placeholder, and a finder for the firmness a player would anticipate.

**Architecture:**
- `planDownswing` checks the head's rise against `body.headRiseLimit` before θ_max, and the solvers and the map clamp
  to it.
- On a held, hands-led downswing the tempo T(i) is solved from a Hill-linear arms' force on the swung mass
  (`assistTempo`), with `body.assist` calibrated as the shaft's effort was.
- `scripts/firmness.ts` searches the hold's share σ for the least admissible play, as the map plays it.

**Tech Stack:** TypeScript, Vitest, tsx scripts.

**Spec:** docs/superpowers/specs/2026-11-03-p2b2b2c3b2-firmness-design.md (parent: push-map design A7 items 4, 12–14).

## Global Constraints

- ENGINE_VERSION "0.29.0" in `src/engine/simulate.ts`, `tests/engine/index.test.ts` and
  `tests/engine/impact/simulateImpact.test.ts`.
- No canonical pin moves: every preset's default play is bit-identical (backswings 0.424–0.449 m < 0.48 m; no preset
  carries an intensity).
- At intensity 0 a held roll's tempo is `handTempo.slow` exactly, bit for bit.
- `headRiseLimit` 0.48 m (the user's ruling); the test profile's is 2 m, as its θ_max is MAX_BACK_ANGLE.
- Both limit messages contain "beyond the body's" (θ_max's already does: "beyond the body's backswing limit θ_max"); every
  matcher that read "θ_max" reads that token.
- No push-map or envelope runs beyond the Gate 1 probe. Long scripts run under `nice -n 20`.
- 4 spaces, 120 columns, UK English. Doc comments on exported APIs cite the spec ("firmness design §4").
- Every re-pinned test value carries a one-line reason in its comment.

## Review Focus

1. A held roll whose hands already reach v_max at T_slow: the arms add nothing, T = T_slow, no NaN (Task 2 test).
2. A stroke with pendulumShare 1, or λ = 0, or a null hand tempo, is untouched by `body.assist` (Task 2 test).
3. A backswing exactly at headRiseLimit plans; one a hair above throws the head-rise message, on the drive too, before
   θ_max (Task 1 test).
4. findFirmness on a plan below HOLD_SPEED searches no σ above v/HOLD_SPEED, and never a firmness above 1 (Task 4 test).
5. A planning RangeError inside findFirmness propagates; it is not swallowed as a class (Task 4 test).

**Interfaces:**
- Produces:

  ```ts
  /** The arms' assist (firmness design §4): F_a = i·force·max(0, 1 − v/speed) along the hands' path. */
  export interface SwingAssist { readonly force: number; readonly speed: number }
  /** T(i) (s): the hands' tempo at which the arms supply the faster swing's extra force (firmness design §4). */
  export function assistTempo(assist: SwingAssist, intensity: number, slow: number, travel: number, mass: number): number
  ```

  `travel` = |Δ_h| (m), `mass` = M (kg). `DownswingInput` gains `assist: SwingAssist` and `swungMass: number`.

- [ ] **Step 1: Failing tests (assist.test.ts).** assistTempo returns `slow` exactly at intensity 0, at force 0 and when
  2·travel/slow ≥ speed; T(i) falls strictly with i; at the returned T the residual
  `mass·2·travel·(1/T² − 1/slow²) − i·force·max(0, 1 − 2·travel/(T·speed))` is within 1e-9 of 0 relative to
  i·force; 2·travel/T < speed. planDownswing: a held roll at intensity 0 equals today's plan to the bit (tempo,
  handsVelocity, omega); its contact speed rises with intensity; a drive's and the AC stop's plans do not change when
  `assist.force` is doubled.
- [ ] **Step 2:** Run them; they fail.
- [ ] **Step 3: Implement.** assistTempo: return `slow` unless `intensity > 0 && force > 0 && 2·travel/slow < speed`;
  otherwise bisect T on [2·travel/speed, slow] for the root of the residual, 60 halvings, returning the upper end (so
  the arms never exceed their force). Both call sites take `assistTempo(input.assist, intensity, handTempo.slow,
  |across|, input.swungMass)`.
- [ ] **Step 4: The calibration (`scripts/assistFit.ts`), as the shaft's (design §4; P2b.2b.2c.1 design §4.4).** For
  each held roll at its body-limited top h = headRiseLimit·(1 − 1e-9) at intensity 1: the hands at contact turn at
  κ·v_max (κ = body `effortShare`, ⅔) and the head meets the ball at CEILING (9 m/s, effortFit's). Parameterise by T₁:
  v_max = 2·|Δ_h|/(κ·T₁), F_0 = M·2·|Δ_h|·(1/T₁² − 1/T_slow²)/(1 − κ); bisect T₁ until plannedSpeed is 9 m/s. Keep the
  pair of the roll whose F_0 is largest (the weakest, as single-ball set τ_0), write it, and print every roll's
  contact speed at intensity 1 with it. Run it under `nice -n 20`.
- [ ] **Step 5:** Run the whole suite; re-pin any intensity > 0 roll test with its reason. format:check, lint, tsc;

  admissible σ*; if σ* > 0, four halvings of [previous grid point, σ*], keeping the admissible end; return the least
  admissible σ found and its firmness.
